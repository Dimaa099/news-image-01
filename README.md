One image summing up the world news of Friday 13 November 2026: a flat editorial collage with five labelled panels covering the FAA ground stop, the Microsoft outage, Ukraine's drone strikes, the NVIDIA CEO's exit, and China's naval drills. The program ships the finished collage and writes it, byte for byte, to the output directory as `entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
